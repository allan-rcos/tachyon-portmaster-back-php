Route.php : 42

One line of a route table: a method, a path, and the controller entry point the pair resolves to.

Identity is the method and the path, not the handler. That is the exact pair FastRoute refuses to see twice, so two rows agreeing on it are the same route as far as routing is concerned, however different their handlers. Being a Key with that identity is what lets a Set answer the unversioned-alias question on its own: fill one newest version first, and the set keeps the newest publisher of every route and drops the rest.

The same rule applies inside a single version. A router declaring the same method and path twice keeps the first declaration and silently drops the second — the set has no way to tell an accident from an override, and the first-wins reading is the one that matches the cross-version rule.
