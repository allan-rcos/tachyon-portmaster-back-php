CoercesJson

CoercesJson.php : 29

Scalar/array coercion helpers for decoding untyped JSON structures.

json_decode() yields mixed for every value, so hydrating a proxy's strictly-typed fields from a decoded body would otherwise scatter is_* guards and casts across every IFbsProxy::jsonUnserialize(). These helpers narrow a single key once, in one place.
