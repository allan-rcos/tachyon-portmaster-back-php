IMarkerGroupRepository.php : 45

The marker-group registry: the runtime catalogue of every marker group a feature declared.

Same metadata contract as IPermissionRepository, over the marker_groups table — see there for why a catalogue derivable from the code is a registry rather than a persistence repository, and for why the reads return bare values instead of Result.

What is particular here is who reads it: every marker operation does, to turn the group slug a caller names into the index actually stored on the marker row. A group that no worker registered therefore makes IMarkerRepository::set() fail with a 404 rather than writing a marker nothing could later find.
