IUserRepository
in
  • Portmaster

IUserRepository.php : 37

Persistence for users — the write side.

Stores what the table module already validated; it does not validate and it does not hash — a user arrives here with its password already digested. Every method enlists in the caller's open transaction, so a use case that rolls back undoes these too.

This contract owns the user_roles pivot: syncRoles() writes it, while IRoleRepository::findByUserId() reads it back.

public syncRoles(string $userId, array<int, string> $roleIds) : Result<string|int, null>
APIYes

A full sync, not a merge: roles left out are removed and roles listed are added, so passing an empty list strips the user of every role. Repeats in the list collapse to one assignment.
