IRoleRepository.php : 38

Persistence for roles — the write side.

Stores what the table module already validated; it does not validate. Every method enlists in the caller's open transaction, so a use case that rolls back undoes these too.

A role carries the permission slugs it grants, so writing a role is what changes an authorization decision. Which users hold a role is the other side of the user_roles pivot and is written through IUserRepository::syncRoles(); only reading it lives here.
